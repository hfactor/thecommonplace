|          |                                                   |
| -------- | ------------------------------------------------- |
| Coffee   | 13g medium or medium-dark roast, medium grind     |
| Water    | 150ml at 85°C to 88°C                             |
| Position | Standard                                          |
| Filter   | 2 paper filters, rinsed                           |
| Beans    | Say Hello to Mellow, SL-28 CM Washed, Jumping Ant |
| Target   | 120ml                                             |

1. Add the coffee.
2. Pour 50ml water, bloom for 30 seconds.
3. Pour the remaining 100ml, insert the plunger to stop dripping.
4. Wait 30 seconds.
5. Press gently over 20 to 30 seconds. Stop before the hiss, or press through it if you want more of the oils.
